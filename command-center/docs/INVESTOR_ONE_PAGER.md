## Install steps (for investor-operators)

1. Receive USB from `INVESTOR_FLASH_MASTER` (sanitized, no `.env`).  
2. Mac: `cd AIX_AI_COMMAND_SYSTEM && ./scripts/setup-mac.sh && cp .env.example .env`  
3. Read `START_HERE.md` → `TMMT MANAGEMENT/OPERATIONS/COMMAND_CENTER.md`  
4. Add **their** API keys (Airtable, Supabase, optional OpenAI).  
5. Optional: deploy `tmmt-os` with their Supabase project.  
6. Run owner routine: `OWNER_DAILY_COMMAND.md` (in operator command center; copy to kit on refresh).
