# Objection Bank

Add every common objection here after sales calls.

## Price

Customer says:

```text
It costs too much.
```

Response:

```text
I understand. Usually when someone says that, it is either the total price, the timing, or uncertainty about the result. Which one is it for you?
```

## Need To Think About It

Customer says:

```text
I need to think about it.
```

Response:

```text
That is fair. To make sure I follow up the right way, what part are you thinking through: fit, price, timing, or trust?
```

## Need To Talk To Someone

Customer says:

```text
I need to talk to my spouse/partner/team.
```

Response:

```text
Makes sense. What do you think they will care about most, and should we set a quick call with them so the answer is clear?
```

## Bad Timing

Customer says:

```text
Now is not a good time.
```

Response:

```text
Understood. Is this something you want handled later, or is it no longer a priority?
```

## Trust Concern

Customer says:

```text
How do I know this will work?
```

Response:

```text
That is a fair question. I would not want you moving forward without clarity either. The way this works is [process]. The main thing we need from you is [customer responsibility]. The part we handle is [TMMT responsibility].
```
