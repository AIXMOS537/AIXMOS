# First 72 Hours

This is the fastest path to control.

## Day 1: Money Visibility

Goal: see bills, cards, income, expenses, and money leaks in one place.

Actions:

1. Import the Airtable CSV templates.
2. Add every bill you know about.
3. Add every credit card.
4. Add every bank account and payment account.
5. Add any unpaid money owed to you.
6. Add known leaks from the last 30 days.
7. Ask AI to create your first money priority list.

Prompt:

```text
Act as my CFO. Here is my current money picture. Tell me the first 10 actions to lower risk, collect money, and stop leaks.
```

## Day 2: Daily AI Operator

Goal: use AI three times a day.

Actions:

1. Paste the master operator prompt into ChatGPT or Claude.
2. Run the morning command.
3. Run the midday rescue.
4. Run the end-of-day closeout.
5. Save useful outputs into Airtable or your task system.

## Day 3: Automate Follow-Up

Goal: stop missing money because nobody followed up.

Actions:

1. Create stale lead views.
2. Create unpaid money views.
3. Create overdue task views.
4. Create bill due views.
5. Create Zapier or Make alerts for each one.
6. Assign one team member to monitor the alerts daily.

## If You Are Leaving For A Month

Also complete these before the end of the first 72 hours:

1. Assign Acting Manager, Sales Lead, Operations Lead, Money Lead, and Admin Recorder.
2. Import the TMMT Airtable templates.
3. Enter every active lead, task, employee, and open decision.
4. Review `00_COMMAND_CENTER/ESCALATION_RULES.md` with the team.
5. Run one full day where the team operates from the dashboard without owner intervention.

## Non-Negotiables

- Every bill goes in the system.
- Every card goes in the system.
- Every lead gets a status.
- Every unpaid balance has an owner.
- Every leak gets a fix and prevention plan.
- Every active deal has a next action.
- Every employee has a role, checklist, and escalation rule.
