# Group Chat Operating System

**For:** Owner (you) · Operators · Overseas VAs · Admin Recorder  
**You do not need Terminal.** Chat is intake; Airtable / TMMT OS is truth.

**Chat language:** English only in all ops/VA group chats (templates, shift posts, rollout). Other languages in `VA_SETUP_TODAY.md` Step 2B are for VA training in private DM only.

# Part 1 — Owner cheat sheet (print or pin)

## Your job in one sentence

Read what the team posted → decide top 3 + one blocker → send one alignment message → done (~20 min).

## Every morning (20 min)

| Min | Do |
|-----|-----|
| 1 | Open group chats (ops, money, fleet — whatever you use) |
| 5 | Skim **BLOCKED** lines and **overdue $** from last shift posts |
| 5 | Open **one** live board (pick what your team keeps current): |
| | • `TMMT MANAGEMENT/OPERATIONS/COMMAND_CENTER.md` |
| | • `TMMT MANAGEMENT/OPERATIONS/DAILY_BRIEF_YYYY-MM-DD.md` |
| | • TMMT OS: https://tmmt-c919-two.vercel.app/login |
| 5 | Paste chat + prompt below into **ChatGPT or Claude** |
| 4 | Act on **top 3 only** (call, approve, or delegate with a name + deadline) |
| 3 | Write top 3 + one blocker in `COMMAND_CENTER.md` (or tell Admin Recorder to) |

Full pillar checklist (money / bookings / fleet / investor): **`OWNER_DAILY_COMMAND.md`**

## Owner AI prompt (copy every morning)

```text
You are my owner-level operator. I run car rentals (main cash), credit repair, business funding, and ecommerce.

Below is what my team posted in group chat. Do NOT ask me to run Terminal, Python, or scripts.

Give me:
1. Top 5 decisions only I should make (not delegate)
2. Top 3 actions for today (revenue, collections, fleet risk)
3. What looks stuck, missing, or contradictory in the chat
4. One short message I should send the team to align them (copy-ready)
5. What can wait until tomorrow

Team updates:
[PASTE GROUP CHAT HERE]
```

## Owner AI prompt (money only — 4 min)

```text
Act as my money operator. From the team chat below: what is the single highest-impact payment to collect or pay today? List overdue by $ if mentioned. Tell me who should own each follow-up.

[PASTE MONEY-RELATED CHAT]
```

## Owner AI prompt (end of day — 3 min)

```text
Summarize today's team chat as owner. What money moved? What's still stuck? What did we avoid? What is #1 tomorrow morning? Keep it under 15 bullets.
```

## What to scan in chat (don't read everything)

| Look for | You decide |
|----------|------------|
| `BLOCKED:` | Yes/no, who owns fix, deadline |
| Overdue $ + customer name | Call/text priority |
| Fleet down / oil change overdue | Schedule or assign today |
| "Waiting on owner" | Answer same day |
| Vague "handled it" with no name/$ | Ask for one clarifying reply |

## What you ignore

- Play-by-play unless it affects cash, fleet, or a customer today  
- Tools talk (Terminal, API, deploy) — that's Admin Recorder / tech lead  
- Tasks without **owner name + due**  

## Your file map

| File | Purpose |
|------|---------|
| `OWNER_DAILY_COMMAND.md` | 20-min all-pillar routine |
| `TMMT MANAGEMENT/OPERATIONS/COMMAND_CENTER.md` | Top 3, tasks, follow-ups, EOD |

## Team rule (pin in every ops chat)

> **If it isn't in the shift post or Airtable by end of day, it didn't happen.**

# Part 3 — Admin Recorder role

## Title

**Admin Recorder** (Command Center) — turns group chat into structured records and the daily brief.

## Purpose

Operators and VAs move fast in chat. The Admin Recorder makes sure **nothing important dies in messages** — it lands in Airtable / TMMT OS and on the command board so the owner can run a 20-minute review without scrolling 500 messages.

## Reports to

Owner (you) · dotted line to Acting Manager if you have one

## You do NOT need

- Terminal (optional bonus skill)  
- Coding  
- Making owner-level decisions (repo vs payment plan, pricing, hiring)

## You DO need

- Reliable English reading (overseas chat OK if they post in short template)  
- Same-day data entry discipline  
- Access to Airtable (edit) and/or TMMT OS (internal login)  
- 1–2 hours/day split: morning intake + end-of-day close

## Daily schedule

| Time | Task | Output |
|------|------|--------|
| **Morning (30–45 min)** | Read overnight + start-of-shift posts | Update `COMMAND_CENTER.md` Top 3 + Active Tasks |
| **Midday (15 min)** | Scan new chat | Add follow-ups; flag `@OWNER ESCALATION` items to owner DM |
| **End of day (45–60 min)** | Read all EOD posts | Fill COMMAND_CENTER EOD notes; update Airtable; post weekly summary on Mondays |

## Core responsibilities

1. **Enforce templates** — remind in chat if someone posts a wall of text without BLOCKED / $ / names  
2. **COMMAND_CENTER** — keep `TMMT MANAGEMENT/OPERATIONS/COMMAND_CENTER.md` current (date, top 3, task table, follow-ups)  
3. **Airtable** — enter or update: leads, team tasks, overdue flags, decision log (per your base schema)  
4. **Daily brief** — if your team uses auto-brief: run or request `TMMT MANAGEMENT/AUTOMATIONS/SCRIPTS/daily_command_center.py` (tech lead can schedule; Recorder verifies file exists for today)  
5. **Owner packet** — by owner’s review time, ensure owner has: latest brief OR COMMAND_CENTER + list of open `@OWNER` items  
6. **No secrets in chat** — never paste API keys, `.env`, or full card numbers  

## What gets entered where

| Chat says… | Goes to… |
|------------|----------|
| New lead | Airtable Leads / Deals + COMMAND_CENTER follow-up |
| Payment received | Airtable payments / customer record |
| Still overdue | `TODAY_COLLECTIONS.md` or payments view + COMMAND_CENTER |
| Task with owner | COMMAND_CENTER Active Tasks table |
| Owner decision needed | COMMAND_CENTER Decisions Needed + ping owner |
| SOP / process gap | Note in COMMAND_CENTER Issues or Decision Log |

## Quality checklist (end of day)

- [ ] Every `BLOCKED` line has owner name or marked "Owner"  
- [ ] Top 5 overdue from money post match Airtable or brief  
- [ ] COMMAND_CENTER date is today  
- [ ] EOD section filled: Wins / Problems / Carryover  
- [ ] No open `@OWNER` older than 24h without status  

## Optional skills (nice to have)

- Run `./scripts/tmmt-day` on Mac and paste output into owner brief (requires `.env` keys — **owner holds keys**, not shared in chat)  
- Basic Zapier/n8n if you automate chat → Airtable later  

## Success metrics (first 30 days)

- Owner morning review ≤ 20 min with no "what happened to X?" surprises  
- 90%+ shifts use START/END template  
- COMMAND_CENTER updated same day  
- Overdue $ in chat matches board within 1 business day  

## Sample job post (copy to hire)

```
Admin Recorder — remote, part-time

We run car rentals + related businesses. Team works in group chat; owner needs one clean daily board.

You will:
- Read ops group chat 2x/day
- Post using our shift templates when others forget format
- Update our Command Center doc + Airtable (training provided)
- Flag owner escalations clearly

Requirements: strong written English, detail-oriented, same-day follow-through, comfortable with spreadsheets/Airtable. No coding required.

Hours: ~1.5–2 hrs/day, 6 days/week (or 5 with weekend coverage swap)
```
