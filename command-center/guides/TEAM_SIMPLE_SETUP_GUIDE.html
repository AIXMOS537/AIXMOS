Lead Assistant (one person)

☐ Post the "Why we are starting" message in Announcements ☐ Post today's Top Jobs in Announcements ☐ Collect roster: every person replies DONE + role in ops chat ☐ Send owner a DM every morning: OWNER BRIEF (see page 4) ☐ Send owner 4 screenshots when pins are done

VA / Assistant (ops chat)

☐ Pin 4 messages in ops chat (START, END, RULE, ESCALATION) ☐ Send rollout message (page 3) ☐ Remind each shift: post START within 15 minutes ☐ If someone posts wrong: ask once to repost with template

Everyone else

☐ Reply in ops chat: DONE + your role (Money / Fleet / Dispatch / VA / Admin) ☐ Use pinned START when you begin work ☐ Use pinned END before you stop work ☐ Always write customer name + dollars for money
