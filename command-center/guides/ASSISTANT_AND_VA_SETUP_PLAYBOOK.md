# Assistant + Virtual Assistant — Full Setup Playbook

**Owner sends this file to:** Lead Assistant + all VAs  
**Time:** 2–3 hours total (split across people)  
**You do NOT need:** Owner's Mac · Cursor · Terminal · API keys

**Owner only approves** when you send the completion report (Step 8).

---

## Roles — who does what

| Role | Person | Today's setup jobs | Every day after |
|------|--------|-------------------|-----------------|
| **Lead Assistant** | _____________ | Community announcement, admin rights, Airtable invites (if owner gives access), proof to owner | OWNER BRIEF to owner DM · escalate to owner |
| **VA Ops** | _____________ | Pin templates in ops chat · rollout message · enforce format | Shift reminders · fix bad posts |
| **VA Overseas** | _____________ | Same pins if separate VA chat · SHORT template · roster `DONE + role` | START/END reminders for their shift |
| **Admin Recorder** | _____________ | (Can be same as Lead Assistant) | COMMAND_CENTER / Airtable · EOD summary |

Fill names in a DM to owner before you start.

---

## What you are setting up

```text
WhatsApp COMMUNITY (owner already has this)
├── Announcements  ← Lead Assistant posts rules + daily command
└── Ops chat       ← VA pins templates · team posts START/END

Owner DM ← Lead Assistant sends OWNER BRIEF every morning
```

**English only** in all team posts. Spanish/Tagalog/Urdu below = **training for VAs only** — never post in team chat.
