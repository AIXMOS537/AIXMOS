```
FIN | Nombre ___ | Fecha ___
```

**RULE (pin):**
```

```

**Rollout — do NOT send in chat** (English rollout is in Step 3). Reference only.

**Rollout (reference — Spanish):**
```
📌 NUEVO FORMATO — empieza hoy

Usen la plantilla INICIO al entrar y FIN al salir (mensajes fijados).

Reglas:
• BLOQUEADO = qué necesitan y de quién (nombre del jefe).
• DINERO = siempre nombre del cliente + monto en dólares (ej: "Juan — $500 — 10 días").
• FIN = liste ATASCADO para mañana (nombre + $ + motivo).
• El dueño solo revisa: BLOQUEADO + mora $ + riesgo con el cliente. Sea breve y factual.

Copien la plantilla. Llenen cada línea. Si no hay nada, escriban "ninguno".
```

**Reminder:**
```
Recordatorio: publiquen INICIO con la plantilla fijada en 15 minutos. Avísenme si no pueden llenar una línea.
```

**If wrong format:**
```
Por favor republiquen con la plantilla INICIO (o FIN) fijada. El dueño solo rastrea BLOQUEADO + mora $ + riesgo — use el formato.
```
