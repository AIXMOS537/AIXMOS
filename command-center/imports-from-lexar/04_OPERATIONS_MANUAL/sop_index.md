# SOP Index

Every repeated task should become an SOP.

## Required SOPs

- Lead intake
- Discovery call booking
- Proposal follow-up
- Closed won onboarding
- Customer issue handling
- Payment collection
- Refund or dispute handling
- Daily manager routine
- Weekly owner update
- Employee onboarding
- Employee correction
- Airtable record cleanup
- Money leak review

## SOP Template

```text
SOP Name:
Owner:
When to use:
Trigger:
Inputs needed:
Steps:
What done looks like:
Common mistakes:
Escalation rule:
Related Airtable table:
Last updated:
```

## SOP Rule

If the same question comes up twice, update the SOP.

If the same mistake happens twice, update the SOP and training.
