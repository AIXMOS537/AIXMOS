# Device Setup Checklist

Use the same system on phone, work computer, home computer, and flash drive.

## Phone

Install or pin:

- ChatGPT
- Claude
- Airtable
- Bank apps
- Credit card apps
- Calendar
- Email
- Team chat
- Voice notes
- Camera or receipt scanner

Create phone shortcuts:

- New task
- New receipt
- New customer issue
- New bill
- New money leak
- New voice note for AI

Daily phone rules:

- Screenshot anything involving money.
- Voice note anything you might forget.
- Put receipts into the expense table the same day.
- Do not let customer issues stay only in texts.

## Work Computer

Pin these tabs:

- Airtable dashboard
- ChatGPT
- Claude
- Email
- Calendar
- Bank dashboard
- Credit card dashboards
- Payment processor
- Team task board
- Vercel dashboard
- Zapier or Make

Create folders:

- AI Command System
- Receipts
- Business Reports
- SOPs
- Contracts
- Customer Docs
- Exports

## Home Computer

Use home computer for:

- weekly money review
- planning
- SOP updates
- automation cleanup
- dashboard review
- content and marketing

Mirror the same folder structure as work computer.

## Flash Drive

Put this folder on the flash drive:

- `AIX_AI_COMMAND_SYSTEM`

Also add:

- exported Airtable backups
- SOPs
- policies
- contracts
- team scripts
- dashboard backups

Do not store passwords or API keys in plain text.

## Daily Desktop Flow

1. Open Airtable.
2. Open AI.
3. Open money accounts.
4. Run the morning command.
5. Assign team tasks.
6. Check money due.
7. Send follow-ups.
