# Daily Manager Dashboard

Use this every business day while the owner is away.

## Morning Standup

Time limit: 15 minutes.

Answer:

- What revenue can move today?
- Which leads need contact?
- Which deals are waiting on a decision?
- Which customer issues could become expensive?
- Which team tasks are overdue?
- Which employee needs training or correction today?
- What must be escalated?

## Pipeline Check

Review every deal in these stages:

- New Lead
- Contacted
- Qualified
- Call Booked
- Proposal Sent
- Negotiation
- Closed Won
- Closed Lost
- Onboarding

Every active deal must have:

- owner
- next action
- next action due date
- expected value
- risk or blocker

## Team Check

For every employee:

- Did they check in today?
- What are their top tasks?
- What training are they completing?
- Are they blocked?
- What does done look like today?

## Midday Rescue

Run this by 1:00 PM:

- leads not contacted
- proposals not followed up
- payments not collected
- customer messages unanswered
- overdue team tasks
- missing documents
- unresolved escalations

## End-Of-Day Closeout

Before closing:

- update all deal statuses
- update all task statuses
- log decisions made
- assign tomorrow's first actions
- send urgent escalations if needed
- save notes for weekly owner update
