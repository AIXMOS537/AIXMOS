# Executive Routing

**Brainiac 7** = supreme. Tiers 6→1 use the same three executives; escalate to **7** when over your tier (see `docs/brainiac-hierarchy.md`).

Use **one** executive per conversation. Switch chats in Open WebUI — no router agent required.

| If you're thinking… | Executive | Command |
|---------------------|-----------|---------|
| What should I do? Which option? What matters? | **Oracle** | `/oracle` |
| Process my notes, daily plan, tasks, follow-ups | **Operator** | `/operator` |
| What should I say? Research, tone, people | **Counsel** | `/counsel` |

## Handoffs (say in chat)

- "Loop in Operator" — after Oracle decides
- "Loop in Counsel" — before sending a message
- "Loop in Oracle" — when Operator finds a strategic fork

## Voice

Speak naturally; one topic per message. See `docs/voice-executive-guide.md`.
