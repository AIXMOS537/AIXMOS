# 📋 Vertical Playbooks
_The SOP + training layer of the [[operator-os]]. One playbook per vertical. Operators read these; scorecards measure how well they follow them._

Each playbook has the same shape so any operator can pick up any vertical:
1. **What this vertical does** + which systems it touches
2. **Roles** that run it
3. **The SOP** — the step-by-step, as checklists (the parts marked `[FILL IN]` are your actual process — tell me and I'll write them in)
4. **The 4 KPIs** for this vertical (feed the [[operator-scorecard-template]])
5. **Training path** — rookie → cleared solo

Playbooks:
- [[rentals]] — 🚗 Vehicle rentals
- [[detailing]] — ✨ Auto detailing
- [[sales-leasing]] — 💰 Sales / leasing
- [[dispatch-fleet]] — 🚦 Dispatch / fleet ops

Onboarding a person into a vertical uses the existing [[onboarding-offboarding]] fast-hire flow + the [[people-hub]] role→systems map.
