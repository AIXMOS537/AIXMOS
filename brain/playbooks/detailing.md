# ✨ Auto Detailing — Playbook
_Part of the [[operator-os]] vertical playbooks. Pairs with [[tmmt-system]], [[people-hub]], [[onboarding-offboarding]]._
_Steps below are **DRAFT defaults** — correct anything that doesn't match how TMMT actually runs._

## What this vertical does
Detail jobs (interior/exterior), scheduling, detailer/VA coordination, and quality control.

## Systems it touches
ClickUp (detail job tasks + checklists) · OpenPhone (customer coordination) · `vendors`/`shops_mechanics_cleaning` (sublet/cleaning) · Calendar (job slots).

## Roles
operator (detailer) · VA (scheduling/coordination) · manager (QA).

## SOP 1 — Book a detail
- [ ] Intake request: vehicle, package wanted, condition, location, date -> ClickUp task
- [ ] Confirm package + price per current menu (e.g. Express / Full Interior / Full Exterior / Showroom)
- [ ] Schedule a slot + assign a detailer
- [ ] Confirm appointment with customer via OpenPhone (time, address, access)

## SOP 2 — Do the detail (attach photos to the ClickUp task)
**Before:** take "before" photos of the whole vehicle.
**Interior**
- [ ] Remove trash + personal items (bag anything found)
- [ ] Vacuum seats, carpets, mats, trunk
- [ ] Wipe + protect dash, console, panels, vents
- [ ] Clean glass (inside)
- [ ] Shampoo/spot-treat seats + carpet if in package
- [ ] Deodorize
**Exterior**
- [ ] Pre-rinse + foam/wash, wheels + tires
- [ ] Dry (no water spots)
- [ ] Clay/decontaminate if in package
- [ ] Wax/sealant/protectant if in package
- [ ] Dress tires + trim; clean glass (outside)
**After:** take "after" photos.

## SOP 3 — QA + close
- [ ] Manager/QA reviews after-photos against the package checklist
- [ ] Fix any misses before customer sees it
- [ ] Customer walkthrough / sign-off
- [ ] Mark complete; request a review

## The 4 KPIs (-> [[operator-scorecard-template]])
- 📋 **SOP adherence:** package checklist fully done, before/after photos attached
- ⚡ **Speed:** job turnaround time
- 📦 **Output:** details completed / week
- ✅ **Quality:** QA pass rate, redo/complaint rate

## Training path
Read playbook -> shadow 2 details -> do supervised with QA on each step -> pass QA 5x in a row -> cleared solo.
