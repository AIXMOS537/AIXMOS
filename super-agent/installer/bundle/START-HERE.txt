==================================================================
  PROJECT AIXMOS  //  4THEPEOPLE  —  one-shot installer
  JARVIS super agent + Project AIXMOS, on any computer.
  Plug in, run one thing, done.
==================================================================

WINDOWS 10 / 11  (everything is inside ONE file)
------------------------------------------------------------------
  1. Double-click  AIXMOS-4THEPEOPLE-Setup.exe
     (Blue "Windows protected your PC" box?  More info -> Run anyway.
      It is unsigned, not unsafe: it installs per-user and never asks for admin.)
  2. Pick who this machine is for:
        1) Student          2) Employee
        3) Business owner   4) Everything
     "Everything" = every feature in one station.
  3. Wait while it installs the local AI (about 2 GB, first time only).
  4. AIXMOS opens in your browser at http://localhost:8770, introduces
     itself, learns what you are building and writes your first plan.

  Options (from a terminal):
    --role student|employee|builder|everything
    --dir PATH   --port N   --no-model   --no-autostart   --quiet

MAC  /  LINUX
------------------------------------------------------------------
  Open the  mac-linux  folder and double-click  AIXMOS-Install.command
  (or in Terminal:  bash install.sh --role everything ). Needs Python 3;
  installs Ollama.

AFTER INSTALL
------------------------------------------------------------------
  Desktop shortcut "AIXMOS"  ->  http://localhost:8770
  Re-run the installer any time to upgrade. Your memory, CRM, settings
  and media are kept.

WHAT IT NEEDS / WHAT IT NEVER DOES
------------------------------------------------------------------
  - Internet once, for Ollama + the model. After that the brain runs offline.
  - 8 GB RAM recommended, ~4 GB free disk.
  - It carries NO passwords, API keys or database keys, and none of the
    owner's own chats, CRM or media. You add your own accounts (email,
    image/video providers) inside the app when you want them.
  - Nothing is sent, posted, paid or deployed without your click.
  - It gives no access to any company's private repositories, databases
    or internal tools, and it never clones a repository for you.
